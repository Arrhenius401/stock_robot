# 开发与维护

本页汇总开发、可选工具与数据维护说明，面向需要知识库、开发调试或维护数据的用户。日常安装与使用见 [README](../README.md)，完整命令见 [使用指南](使用指南.md)。

## 模型输出预算

`llm.max_tokens` 默认是 `null`（自动）；填写正整数表示显式上限。自动模式与截断恢复的详细行为见[使用指南 · 模型输出预算](使用指南.md#模型输出预算)。

## RAG（可选）

知识库和 Agent 检索能力需要可选依赖。在项目虚拟环境中安装：

Windows PowerShell：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[rag]"
```

Linux：

```sh
./.venv/bin/python -m pip install -e ".[rag]"
```

不安装 RAG 不影响分析、报告、指数、雷达和订阅；Web 对话只是不注册知识库检索工具。用法见[使用指南](使用指南.md)。

## 架构概览

```
┌──────────────────────────────────────────────────┐
│                  接口层                           │
│   CLI (click)  │  HTTP API (FastAPI)  │  Web UI  │
└────────────────────┬─────────────────────────────┘
                     │
┌────────────────────▼─────────────────────────────┐
│               Agent 核心                          │
│   Planner (任务拆解)  +  Executor (逐步执行)       │
│   Memory (对话/计划/事实)  +  ToolRegistry (注册)  │
│   pipeline_tools  │  rag_tools  │  mcp_tools     │
└────────────────────┬─────────────────────────────┘
                     │
┌────────────────────▼─────────────────────────────┐
│                 引擎层                            │
│   Pipeline (存量)  │  RAG (ChromaDB)  │  MCP GW   │
└──────────────────────────────────────────────────┘
```

- **管道入口** — `analyze` / `index` 命令不变，直接走 Pipeline
- **工具统一** — 所有工具实现 `ToolProtocol`，Agent 不感知工具来源
- **分层隔离** — Agent 核心与分析管道分层

## 扩展开发

### 添加新的 LLM

在 `src/llm/` 下创建新的适配器（实现 `LLMBackend` 接口），然后在 `_register_llm` 中注册。

### 暴露本地工具给外部 MCP 客户端

通过 `MCPGateway.register_local_tool()` 注册任意 `ToolProtocol` 实例，然后调用 `gateway.serve_stdio()` 以 stdio MCP Server 模式运行。工具会自动通过 MCP 协议的 `tools/list` 和 `tools/call` 暴露。

## 港股行业数据

`stock-robot hk-industry-refresh` 可手动更新港股通成员与恒生 HSICS 行业快照。命令先发布上交所港股通成员快照，再刷新 HSICS 行业快照；两步数据独立，后一步失败不会回滚已成功的成员快照。完整安装与命令用法见 [使用指南](使用指南.md)。
