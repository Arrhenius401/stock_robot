# 单股报告信号回测实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为单只 A 股的报告技术信号提供可复现、可审计的本地日线回测 CLI。

**Architecture:** 新建 `backtest` 包，将策略加载、历史数据、信号生成、VectorBT 组合仿真和产物落盘分开。CLI 只解析参数并调用 `BacktestRunner`；策略与成本从 YAML/全局配置读取，运行时把完整快照写入 `manifest.json`。

**Tech Stack:** Python 3.11、Pydantic v2、Click、pandas、VectorBT 社区版、AkShare、PyYAML、pytest。

**Spec:** `docs/superpowers/specs/2026-08-29-单股报告信号回测设计.md`

## Global Constraints

- 第一期开只支持单只 A 股日线，不做组合、分钟/tick、实盘或第三方商业平台。
- 仅使用历史 OHLCV 重算技术评分；禁止把当前财务、估值、行业、新闻或 LLM 数据带入历史。
- 信号在当日收盘生成，订单必须在下一有效交易日开盘成交。
- 策略 ID 仅限小写字母、数字和下划线；配置变更由 `version` 标注，并始终计算配置短哈希。
- 默认基准为 H11025；可选 `000300` 与 H11001；基准数据不可用必须失败而非填零。
- 产物路径固定为 `reports/backtests/<策略ID>/<股票代码>/<YYYY-MM>/<运行ID>/`；股票/指数报告分别迁至 `reports/stock/`、`reports/index/`，不迁移历史文件。
- 代码注释与文档使用中文；所有 Python 验证命令使用 `.venv/Scripts/python -m pytest`。
- 不运行全量检查；每个任务只运行关联测试、Ruff 与 Pyright 单文件检查。

## 文件结构

| 文件 | 职责 |
|---|---|
| `src/backtest/models.py` | Pydantic 配置、策略、成本、基准、运行结果和错误模型。 |
| `src/backtest/strategy.py` | 策略 YAML 的发现、加载、重复 ID 校验、规范化 JSON 与短哈希。 |
| `src/backtest/data.py` | 历史个股/基准行情的日期裁剪与 DataFrame 标准化。 |
| `src/backtest/signal.py` | 仅基于截至当日 OHLCV 的技术评分与三档仓位序列。 |
| `src/backtest/runner.py` | 调用 VectorBT 进行次日开盘调仓、成本处理、指标汇总。 |
| `src/backtest/artifacts.py` | 运行 ID、目录、五类结果文件和 Markdown 报告。 |
| `config/strategies/report_technical.yaml` | 默认报告技术信号策略。 |
| `src/utils/config.py` | `backtest` 默认配置、成本档与基准目录。 |
| `src/data/akshare.py` | 价格数据按指定历史起止日拉取；新增指数收盘序列入口。 |
| `src/report/formatter.py`、`src/stock_robot/cli.py` | `reports/stock`、`reports/index` 保存路径与 `backtest` 命令。 |
