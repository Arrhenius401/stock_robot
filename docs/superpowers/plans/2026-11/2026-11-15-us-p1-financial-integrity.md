# 美股 P1 财报完整性与估值口径实施计划

## 范围与依据

按用户确认的外部交接顺序执行，外部文档不复制、不移动、不提交。原地在 dev 实施，保留所有者暂存的发布文件，不操作插件、不推送、不发布。业务规则由本轮用户明确指定，不另扩展评分或事件能力。

## 步骤与验收

1. 探针：类别股、银行保险、三市场资本开支、ADR、非标准财季、百度近一年。原始响应及临时报告仅放 tmp/us-p1-probe 与 tmp/us-p1-cli。
2. 类别股：仅将 BRK.B 映射至实测可用的 BRK_B，校验两种返回身份；拒绝错配。
3. 银行保险：按科目族映射财务事实，毛利率及现金流三行明确不适用。
4. 三市场现金流：可选资本开支和自由现金流字段兼容旧缓存；支出统一正值；累计报表按本期加上年全年减上年同期，美股四季求和；缺项不补零，不扩大覆盖率分母。
5. ADR 与财季：无币种证据不标美元、不推断换汇或每股比例；无起点不推造自然季度，保留源报告日。
6. ROE：TTM 归母净利润除以最近可得期末归母权益，不年化；披露分母日期；负权益及 TTM 缺失单独说明；不再回退年报主列。
7. 估值：百度同源实测近一年，120 个有效日期样本门槛，严格小于当前值占比；独立于行情长度，缺失价格保持空值。A 股实测失败才保留明确标注的派生参考。PS 必须币种可比，并披露市值日期与四季营收截止期；负权益与非正营收禁用对应估值。
8. 新闻：七个 A/港股公司别名与泛词回归；事件数据延后，不从标题推断。

## 探针结论

- BRK_B 三表返回 BRK_B / BRK_B.N / 伯克希尔哈撒韦-B；点号、横线、斜线和 BRK.A 失败。已有稳定同类别来源，不启动 SEC 回退。
- JPM/BAC 银行科目族为 001，BRK_B 为 002；普通公司为 004。
- A 股资本开支为购建固定资产、无形资产和其他长期资产支付的现金；港股为 005005、005007；美股为 005002、005004。美股支出有负号，港股支出为正。
- TSM/BABA 三表未提供币种字段，统一披露未核实，禁止与美元市值直接相除。
- COST 财季源报告日含 2026-08-30、2026-05-10，不能据月末展示日期推算自然季度起点。
- 600519 百度近一年两条原始曲线各有 366 个日期记录，按近一年与正数条件筛选后统计。
