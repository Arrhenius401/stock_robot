## 1. 边界与前置

### 1.1 范围

- 只改个股指数报告：A 股宽基/行业/策略、港股、美股/海外。
- 统一 `IndexProfile` 能力矩阵和 `IndexResearch v2` 综合研判。
- 补美股 CPI/10Y、港美市场新闻；过期指标和不可用估值明确标注。
- 不改批量比较表、指数目录、推送、插件和历史归档。

### 1.2 工作方式

- 从 `dev` 当前提交 `0c30943` 创建独立工作树，例如 `codex/index-unify`。该提交已包含个股 v2、共享渲染器、报告库和港股新闻提示的 5 个本地提交，是本项目基线；不要再用旧的 `10c6d3d`。
- 本设计与计划当前是主工作树的未提交文件；新工作树需先复制到 `docs/superpowers/` 对应目录。
- 测试先行；每个阶段先补失败测试，再实现。
- 不默认运行全量门禁；合并/发布前再执行 `.\scripts\verify.ps1 -Scope Full`。
- 不修改 `CHANGELOG.md` 和 `src/stock_robot/metadata.py`，除非用户明确要求。
- 所有 Python 命令使用 `.venv/Scripts/python`。
- 真实服务验收使用 `./.venv/Scripts/stock-robot.exe run --host 127.0.0.1 --port 8765` 和内置浏览器。

## 5. Phase 2：IndexResearch v2 确定性部分

目标：三市场综合研判统一结构，先不调模型。

任务：

1. 新增 `src/index/research.py`。
   - `build_index_research(ctx, report, results, profile) -> dict`：
     - `version=2`、`market`、`style`、`profile`；
     - `positioning`：市场/风格、跟踪指数/ETF、收益口径、数据区间、估值口径；ETF 从 `ctx.requested_instrument` 读取，采集器已在 build 前写入，不能依赖 pipeline 返回后的 `report.requested_instrument`；
     - `dimensions`：按 `profile.dimensions` 生成，五项/四项动态；
     - `evidence`、`risk_candidates`、`model=None`、`limitation`；
     - `business` 不适用，不生成。
   - 规则函数：
     - 技术：收盘与 MA5/MA20/MA60 关系、ADX/ATR/价格位置、OHLC 完整性；
     - 估值：PE/PB 分位、快照/历史口径、有效性；
     - 资金：A 股北向/主力/融资；港股南向市场背景；美股不适用；
     - 宏观：A 股国内、港股 HIBOR、美股 CPI/10Y（Phase 4 前可先占位）；
     - 新闻：A 股市场新闻、港美市场新闻（Phase 4 前可先占位）；
     - 策略：官方权重覆盖、专项指标、样本限制；

   - `render_index_research(research) -> str`：
     - `### 指数定位`
     - `### 核心结论`（仅 model 存在）
     - `### 维度解读`
     - `### 风险提示`（仅 model 存在）

4. 修改 `src/api/static/js/report-renderer.js`。
   - 新增 `indexResearchBody(research, state)`：
     - 指数定位 rows；

## 6. Phase 3：模型 JSON、重试与存档
