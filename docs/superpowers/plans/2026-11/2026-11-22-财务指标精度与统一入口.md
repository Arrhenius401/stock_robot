## 已验证 API 事实

AkShare 当前提供 stock_financial_abstract_new_ths、stock_financial_cash_new_ths、
stock_financial_debt_new_ths；长表列含 report_date/metric_name/value/yoy。
旧摘要及旧现金流返回亿元缩写；新版返回原生基本单位值。
新版摘要的上年同期扣非可能缺失；源同比仍可独立使用，但不强拼旧摘要金额。
完整探针响应留 tmp，测试样本只截取 688836 的相关报告期与字段，
来源为同花顺经 AkShare 读取，采样日 2026-11-22；不含公告核对。
