## 1. 边界与前置

### 1.1 范围

- 只改个股报告：A 股、港股、美股。
- 统一报告骨架和 v2 解读结构；补港美主营业务、美股年度参考期、美股银行专项事实。
- 不改指数、黄金、雷达、推送、插件。
- 不改评分公式、权重、信号阈值、覆盖率分母。
- 不改写历史报告；旧归档继续走 legacy 渲染。

### 1.2 工作方式

- 从 `dev` 当前提交 `10c6d3d` 创建独立工作树，例如 `codex/market-unify`；不推送、不合并、不发版。
- 本设计与计划当前是主工作树的未提交文件；若使用新工作树，先把两份文档复制到工作树的 `docs/superpowers/` 对应目录，或直接在主工作树执行。
- 测试先行：每个阶段先补失败测试，再实现，再跑相关范围。
- 不默认运行全量门禁；合并或发布前再执行 `.\scripts\verify.ps1 -Scope Full`。
- 不修改 `CHANGELOG.md` 和 `src/stock_robot/metadata.py`，除非用户明确要求。
- 所有 Python 命令使用 `.venv/Scripts/python`。
- 真实服务验收使用 `./.venv/Scripts/stock-robot.exe run --host 127.0.0.1 --port 8765` 和内置浏览器。

## 2. 已核实接口事实（2026-11-18 探针）

### 2.1 港美公司资料

| 市场 | 端点 | 过滤 | 关键字段 | 实测 |
|---|---|---|---|---|
| 港股 | `https://datacenter.eastmoney.com/securities/api/data/v1/get`，`reportName=RPT_HKF10_INFO_ORGPROFILE` | `(SECUCODE="00700.HK")` | `MAIN_BUSINESS`、`ORG_PROFILE`、`ORG_NAME`、`SECUCODE`、`SECURITY_CODE`、`BELONG_INDUSTRY` | 00700.HK 返回 1 行；`MAIN_BUSINESS` 是完整业务描述 |
| 美股 | 同上，`reportName=RPT_USF10_INFO_ORGPROFILE` | `(SECURITY_CODE="AAPL")` | `ORG_PROFILE`、`ORG_NAME`、`SECUCODE`、`SECURITY_CODE`、`BELONG_INDUSTRY` | AAPL 返回 1 行；有 `ORG_PROFILE`，无 `MAIN_BUSINESS` |

请求参数：`columns=ALL`、`pageNumber=1`、`pageSize=20`、`client=PC`；港股 `source=F10`，美股 `source=SECURITIES`。本次探针在带/不带环境代理下均成功。

原始响应保存在 `tmp/market-unify-probe/`：`hk-profile-trustenv-0.json`、`us-profile-trustenv-0.json`；脚本为 `probe_orgprofile.py`。

### 2.2 美股年度与银行专项

`RPT_USF10_FN_GMAININDICATOR` 和 `RPT_USF10_FN_BMAININDICATOR` 均含 `DATE_TYPE=年报` 行。

GMAIN 可用字段：

- `REPORT_DATE`、`START_DATE`、`REPORT_TYPE`、`CURRENCY_ABBR`
- `OPERATE_INCOME`、`OPERATE_INCOME_YOY`
- `PARENT_HOLDER_NETPROFIT`、`PARENT_HOLDER_NETPROFIT_YOY`
- `NET_PROFIT_RATIO`、`ROE_AVG`

BMAIN 可用字段：

- `REPORT_DATE`、`START_DATE`、`REPORT_TYPE`、`CURRENCY`
- `TOTAL_INCOME`、`TOTAL_INCOME_YOY`
- `PARENT_HOLDER_NETPROFIT`
- `NET_INTEREST_INCOME`、`LOAN_LOSS_PROVISION`
- `LOAN_DEPOSIT`、`LOAN_ASSETS`、`DEPOSIT_ASSETS`
- `ROE`、`ROA`

单位：

- GMAIN 的 `OPERATE_INCOME_YOY`、`NET_PROFIT_RATIO`、`ROE_AVG` 是百分数。
- BMAIN 的 `ROE`、`ROA` 是百分数；`LOAN_DEPOSIT`、`LOAN_ASSETS`、`DEPOSIT_ASSETS` 是 0—1 比率。
- 金额为来源币种（JPM/AAPL 为 USD）。

已核对样本：JPM FY2025 `TOTAL_INCOME=182447000000`、`NET_INTEREST_INCOME=95443000000`、`LOAN_LOSS_PROVISION=14212000000`、`LOAN_DEPOSIT=0.58352570214`、`ROE=15.740071405316`、`ROA=1.289249474564`；AAPL FY2026 `OPERATE_INCOME_YOY=15.0597965691`、`NET_PROFIT_RATIO=27.6035118642`、`ROE_AVG=142.2567347949`。

## 8. 风险与回滚

- 模型 JSON 不稳定：保留确定性五维；不增加修复调用；记录失败样本。
- F10 网络波动：缓存、超时、失败降级；不因失败阻断整份报告。
- A 股输出漂移：以基线 Markdown 逐字 diff 作为门禁；任何差异先修。
- 旧报告兼容：不删除 legacy 分支；用旧 payload/旧 Markdown 做回归。
