# 港股个股分析实施计划

## 范围

支持 `00700`、`00700.HK`、`hk00700` 三种港股输入，统一为 `00700.HK`。保持现有报告版式、CLI、HTTP 接口和 Web 调用方式。首期不包含港股回测、推送、雷达、汇率换算、H/A 合并证券或港股综合评分。

## 实施

1. 让符号工具识别市场：A 股保持六码与 `sh`/`sz` 行为；港股只接受五位代码、`.HK` 或 `hk` 前缀，杜绝 `00700` 被补零为 `000700`。
2. 令 AkShare 适配器为港股调用日线、财务指标和实时指标接口，再映射到现有价格、财务和估值 Schema；上游失败仅令对应维度不可用。
3. 管道把市场传至上下文。港股跳过 A 股申万分类、同行池与评分配置；报告保留章节并透明显示“不适用”，不产生 A 股操作信号。
4. CLI/API 使用同一市场解析规则，报告和缓存键使用标准代码。

## 验收

离线测试覆盖输入标准化、A 股回归、港股日线/财务/估值映射及港股评分降级。执行相关 Ruff、Pyright 与 pytest；以真实服务和浏览器提交 `00700.HK` 与一只 A 股，确认响应和报告版式。
