- 主仓 D:\code\stock_robot；插件仓 D:\code\astrbot_plugin_stock_robot。分别使用各自 `.venv/Scripts/python.exe`，命令采用 PowerShell。

- 本计划不自动推送、合并或发布。阶段 A 必须进入实际下载的归档，才能验收纯核心安装。
- 探针、归档、日志、截图放忽略目录；失败保留诊断，凭据不提交。

2026-10-03 已确认设计修订：安装标记不依赖模型配置；首次复制模型后由服务独立管理；默认归档固定到验收版本；重装保留状态；运行期健康探测失败不结束存活进程。“自动准备”限定在受支持环境，具体 tag/commit 与清单安装结果仍待探针回填。

## 行为约定

| 情形 | 行为 |
|---|---|
| health 成功 | 复用，不获取外部进程所有权 |
| 远程地址或 auto_install=false | 只探测，不安装，也不启动已有副本 |
| 启用、本机、允许安装 | 后台确保完整实例并启动 |
| 调用时已有准备任务 | 限时等同一任务；超时不取消后台任务 |
| 调用时无任务、已有完整副本 | 可启动或重启，不下载、不安装、不修复配置 |
| 调用时实例不完整或安装失败 | 保留原因，提示重载插件重试 |
| 自建进程存活但不健康 | 返回诊断，保留进程；不因探测失败自动重启 |
| 启动超时或提前退出 | 回收本次进程与日志句柄，记失败原因 |
| 停用 | 阻止新任务，取消并等待准备任务，回收安装/服务进程，再关闭 client |

端口唯一来自 base_url，不新增 startup_port。自动启动仅限回环地址、无路径前缀的 HTTP URL；远程 HTTPS/带路径 URL 仍可复用。无效配置转成可读诊断。

health 要求 HTTP 200、JSON 对象及 status=ok；任意 200 页面不算健康，此检查不是身份认证。

## 阶段 C：插件实现

### 接口与所有权

产品模块使用包内相对导入，launcher 导入 .bootstrap。测试按正式包结构导入，不依赖 sys.path 插入插件目录掩盖错误。

```python
# 类型与中文注释在实现时补齐
async def download_source(archive_url, instance) -> StepResult: ...
async def make_env(instance, extras, *, runner) -> StepResult: ...
def write_config(instance, llm, port) -> StepResult: ...
async def ensure_instance(instance, archive_url, extras, *, runner) -> StepResult: ...
def instance_ready(instance, extras) -> bool: ...

class ServiceLauncher:
    def start_background(self) -> None: ...
    async def ensure_ready(self, *, wait_timeout: float) -> ReadyOutcome: ...
    async def stop(self) -> None: ...
```

launcher 持有唯一准备任务和进程句柄，main 不持有第二个任务。状态 idle/starting/ready/failed/stopped。任务创建用短临界区，下载/安装/轮询不持有等待锁。安装失败保留原因至重载；完整副本服务崩溃可在后续调用重启。

**4.2 先写归档回归，再写 extract_archive。** 在 test_bootstrap.py 用 BytesIO/ZipFile 构造两种 ZIP：正常顶层目录、含 ../../evil 的 ZIP。断言正常 pyproject 位于 src 根，恶意 ZIP 返回失败且正式 src 不存在。函数以磁盘 archive 参数代替旧版 data: bytes，避免整份下载常驻内存。

下面函数追加到 bootstrap.py。保留已存在且通过检查的 src；不合格的旧 src 先报错，不覆盖用户目录：

```python
def extract_archive(archive: Path, src_dir: Path, archive_url: str) -> StepResult:
    """先校验、临时解压，成功后才发布源码目录。"""
    src_dir.parent.mkdir(parents=True, exist_ok=True)
    if src_dir.exists():
        if (src_dir / "pyproject.toml").is_file() and (src_dir / ".bootstrap-source.json").is_file():
            return StepResult(True, "源码已存在")
        return StepResult(False, "旧源码目录不完整或无来源记录，请停用插件后检查")
    try:
        with tempfile.TemporaryDirectory(dir=src_dir.parent, prefix="extract-") as temp:
            staging = Path(temp) / "source"
            staging.mkdir()
            root = staging.resolve()
            with zipfile.ZipFile(archive) as zf:
                files = [info for info in zf.infolist() if not info.is_dir()]
                if not files:
                    return StepResult(False, "压缩包没有文件")
                tops = {info.filename.split("/", 1)[0] for info in files}
                strip = len(tops) == 1 and all("/" in info.filename for info in files)
                targets = []
                for info in files:
                    name = info.filename
                    if "\\" in name or name.startswith("/") or ":" in name:
                        return StepResult(False, f"压缩包路径不合法：{name}")
                    if ".." in name.split("/") or stat.S_ISLNK(info.external_attr >> 16):
                        return StepResult(False, f"压缩包路径越界或链接：{name}")
                    relative = name.split("/", 1)[1] if strip else name
                    target = (staging / relative).resolve()
                    if not target.is_relative_to(root):
                        return StepResult(False, f"压缩包路径越界：{name}")
                    targets.append((info, target))
                for info, target in targets:
                    target.parent.mkdir(parents=True, exist_ok=True)
                    with zf.open(info) as source, target.open("wb") as destination:
                        shutil.copyfileobj(source, destination)
            if not (staging / "pyproject.toml").is_file():
                return StepResult(False, "压缩包缺少 pyproject.toml")
            # 源码来源随完整源码原子发布，供中断恢复和安装标记引用。
            import hashlib

            with archive.open("rb") as stream:
                digest = hashlib.file_digest(stream, "sha256").hexdigest()
            (staging / ".bootstrap-source.json").write_text(
                json.dumps({"archive_url": archive_url, "archive_sha256": digest}),
                encoding="utf-8",
            )
            staging.rename(src_dir)
    except (OSError, zipfile.BadZipFile, RuntimeError) as exc:
        return StepResult(False, f"解压失败：{exc}")
    return StepResult(True)
```

**4.3 下载函数的具体顺序。** 在 extract_archive 后定义 async download_source(archive_url, instance)：

1. 已有 src/pyproject.toml 和有效 .bootstrap-source.json 则复用；旧目录无来源记录先报检查诊断，不伪造来源。无可复用源码且 archive_url=None 时返回“尚未配置已验收归档”，不能请求字符串 None 或偷偷用 main。
2. instance.mkdir；在 instance 内 TemporaryDirectory，归档文件命名 source.zip。
3. `asyncio.timeout(300)` 内创建 AsyncClient(follow_redirects=True, timeout=30)，`async with client.stream("GET", archive_url)`；raise_for_status 后逐块 aiter_bytes 写文件。
4. 完成后调用 extract_archive(archive, src_dir, archive_url)；HTTPError、TimeoutError、OSError 转脱敏失败。取消不捕获，临时目录由上下文清理。归档测试补传 ARCHIVE_URL 并断言来源记录随源码发布。
5. 测试仍放 test_bootstrap.py，respx 返回内存 ZIP，断言最终源码；404 与损坏 ZIP 参数化，不新增下载测试文件。

**4.4 环境安装分成两个函数，不把进程逻辑混在 make_env 内。**

- run_command(cmd, cwd, *, log_path)：create_subprocess_exec 参数用列表；stdout=PIPE、stderr=STDOUT；逐行实时追加 log_path，deque(maxlen=5) 存尾部；保存 proc，try/finally 负责回收。main 用 functools.partial 绑定 log_path 后仍满足两参数 Runner 接口。
- Windows 安装进程回收用 `taskkill /PID <自建 PID> /T /F`（create_subprocess_exec，不拼 shell）；POSIX 以 spawn_kwargs 创建的独立会话调用 killpg，先 TERM 后等 5 秒再 KILL。操作仅针对保存的自建 PID。回收失败保留句柄和明确异常。
- 安装超时用 asyncio.timeout(INSTALL_TIMEOUT_SECONDS) 包住读输出/等待；CancelledError 分支执行回收后重新 raise。创建期间取消用 shield 保留创建任务，取得 proc 后再清理。
- 日志脱敏至少屏蔽 URL 中 userinfo、常见 api_key/token 参数；不要把完整 pip 命令/带凭据索引 URL直接发送给聊天用户。

make_env 的命令拼装按下面顺序实现；Runner 由参数注入，测试无需真建环境：

```python
async def make_env(instance: Path, extras: str, *, runner: Runner) -> StepResult:
    """创建指定解释器环境并安装核心包或 rag extra。"""
    if extras not in {"", "rag"}:
        return StepResult(False, "bootstrap_extras 只接受空或 rag")
    source = instance / "src"
    if not (source / "pyproject.toml").is_file():
        return StepResult(False, "源码缺少 pyproject.toml")
    python = venv_python(instance)
    uv = shutil.which("uv")
    if not python.exists():
        create = (
            [uv, "venv", "--python", sys.executable, str(instance / "venv")]
            if uv else [sys.executable, "-m", "venv", str(instance / "venv")]
        )
        code, output = await runner(create, instance)
        if code:
            return StepResult(False, f"创建环境失败：{output}")
    if not uv:
        code, _ = await runner([str(python), "-m", "pip", "--version"], instance)
        if code:
            code, output = await runner([str(python), "-m", "ensurepip"], instance)
            if code:
                return StepResult(False, f"补装 pip 失败：{output}")
    requirements = source / ("requirements-rag.lock.txt" if extras == "rag" else "requirements-core.lock.txt")
    if not requirements.is_file():
        return StepResult(False, "源码归档缺少对应锁定安装清单")
    install = (
        [uv, "pip", "install", "--python", str(python), "--require-hashes", "-r", str(requirements)]
        if uv else [str(python), "-m", "pip", "install", "--require-hashes", "-r", str(requirements)]
    )
    code, output = await runner(install, source)
    if code:
        return StepResult(False, f"锁定依赖安装失败：{output}")
    project_install = (
        [uv, "pip", "install", "--python", str(python), "--no-deps", "-e", "."]
        if uv else [str(python), "-m", "pip", "install", "--no-deps", "-e", "."]
    )
    code, output = await runner(project_install, source)
    return StepResult(code == 0, "" if code == 0 else f"项目安装失败：{output}")
```

先用假 Runner 记录 commands，再参数化 uv 有/无、安装失败三种情况；安装失败不能写完成标记。

**4.5 配置和完成标记。** 在 bootstrap.py 追加：

```python
def write_config(instance: Path, llm: dict | None, port: int) -> StepResult:
    """首次写配置；已有文件由配置阶段校验，不参与安装标记。"""
    path = instance / ".stock_robot" / "config.yaml"
    if path.exists():
        return StepResult(True, "保留已有配置")
    valid_llm = (
        isinstance(llm, dict) and llm.get("provider") in {"openai", "claude"}
        and bool(llm.get("api_key")) and bool(llm.get("model"))
    )
    effective_llm = llm if valid_llm else {"enabled": False}
    if not valid_llm:
        logger.warning("模型配置未复制，服务将降级；请在自举服务 Web UI 配置模型")
    path.parent.mkdir(parents=True, exist_ok=True)
    temporary = path.with_suffix(".yaml.tmp")
    try:
        with temporary.open("w", encoding="utf-8") as stream:
            os.chmod(temporary, 0o600)
            yaml.safe_dump({"llm": effective_llm, "api": {"host": "127.0.0.1", "port": port}}, stream, allow_unicode=True)
        temporary.replace(path)
    except OSError as exc:
        return StepResult(False, f"写配置失败：{exc}")
    finally:
        try:
            temporary.unlink(missing_ok=True)
        except OSError:
            logger.debug("未清理配置临时文件：%s", temporary, exc_info=True)
    return StepResult(True)


def instance_ready(instance: Path, extras: str) -> bool:
    """只判断程序安装完整性，不把模型配置当成安装条件。"""
    try:
        marker = json.loads((instance / "install-state.json").read_text("utf-8"))
        source = json.loads((instance / "src" / ".bootstrap-source.json").read_text("utf-8"))
    except (OSError, ValueError):
        return False
    if not isinstance(marker, dict) or not isinstance(source, dict):
        return False
    if marker.get("version") != 1 or marker.get("extras") != extras:
        return False
    if marker.get("source") != source or marker.get("dependency_strategy") != "locked-requirements-v1":
        return False
    if not source.get("archive_url") or not source.get("archive_sha256"):
        return False
    return (
        (instance / "src" / "pyproject.toml").is_file()
        and venv_python(instance).is_file()
        and venv_launcher(instance).is_file()
    )
```

**4.6 编排 ensure_instance。** 顺序严格为：

1. instance_ready 为真直接成功。
2. download_source → make_env，任一步失败返回；本函数不调用 write_config。

**5.3 共享任务创建。** 类内添加以下方法；这里的 _prepare 在 5.5 实现：

```python
def _get_or_create_task(self, allow_install: bool):
    """无 await 的短区段，事件循环内不会创建两个任务。"""
    if self._stopped:
        return None
    if self._task is None or self._task.done():
        self._task = asyncio.create_task(self._prepare(allow_install))
        self._task.add_done_callback(self._observe_task)
    return self._task


def start_background(self) -> None:
    self._get_or_create_task(allow_install=True)


def _observe_task(self, task) -> None:
    if task.cancelled():
        return
    error = task.exception()
    if error is not None:
        logger.error("服务准备任务异常：%s", type(error).__name__)
```

这段必须从同一事件循环调用；线程并发不在本期范围。后台异常日志只记录类型，具体诊断由 _prepare 脱敏后记录。

**5.4 调用限时等待。** 同一个 task 无论有几个等待者，超时只结束该等待者：

```python
async def ensure_ready(self, *, wait_timeout: float) -> ReadyOutcome:
    if self._stopped:
        return ReadyOutcome(False, "插件已停用")
    if wait_timeout <= 0:
        return ReadyOutcome(False, "本次工具调用没有剩余等待时间")
    task = self._get_or_create_task(allow_install=False)
    if task is None:
        return ReadyOutcome(False, "插件已停用")
    try:
        return await asyncio.wait_for(asyncio.shield(task), timeout=wait_timeout)
    except TimeoutError:
        return ReadyOutcome(False, "服务仍在安装或启动中，详见插件日志")
```

先写可控 Event 测试：后台准备等 Event；两次 ensure_ready 都限时返回；task 未取消；set Event 后第三次调用可成功。单飞测试明确统计 _prepare/spawn 调用次数，不能只断言两个结果成功。

**5.5 _prepare 的分支顺序。** 按以下顺序实现，顺序就是状态机，不把下载放进 ensure_ready：

1. stopped 返回失败；health 成功设 ready、返回成功。
2. URL 非回环/本机不支持的 scheme/path，或 auto_install=false，返回失败，不检查入口后偷偷启动。
3. 已有自建进程存活而不健康：返回“进程仍运行，健康探测失败，请查看日志”，保留引用，不 terminate、不 spawn。确认 returncode 非 None 后才清理旧句柄并继续。
4. instance_ready 为假：allow_install=false 时返回已有安装原因；true 时设 starting，调用 ensure_instance。失败保留原因。
5. 启用时独立准备配置：文件不存在才加载模型并 write_config；缺 provider 可写 enabled=false。已有 YAML 不合法则诊断，不覆盖、不重装。调用期发现配置缺失/不合法只报配置错误，不补配置。
6. 再检查 stopped，然后 _start。具体边界错误转失败；CancelledError 不吞，由 finally/stop 清理。

**5.6 _start 的创建与轮询。**

- 命令列表是 `[str(venv_launcher(instance)), "run", "--host", host, "--port", str(port)]`，cwd=instance，stdout/stderr 写 service.log。
- create_subprocess_exec 单独建任务并 shield；若此时取消，await 创建任务取得 proc、登记并清理后 re-raise。不要在创建结果未取回时关闭 stdout 句柄。
- 保存局部 proc 后轮询，不反复从 self._process 读取；deadline=loop.time()+timeout。每次 health 用剩余时间再限制一次，不能超出总截止时间。
- 成功保留自建句柄；提前退出/超时/异常必须调用回收函数并等待，然后返回失败。日志句柄在退出确认后关闭，旧引用不可被覆盖。

在 test_launcher.py 用假进程参数化提前退出、超时、正常启动；失败后断言没有存活旧进程，再次请求仅产生一个新进程。

**5.7 stop 的顺序。** 用 _stop_lock 串行化重复 stop：设置 stopped → cancel 准备 task → await 并仅捕获 CancelledError → 回收自建服务 → 关闭日志。准备 task 中 Runner 已负责安装进程树回收。进程回收失败保留引用，不设“已清理”。对复用外部服务不持有句柄，也不调用 terminate。

**5.8 本步完成条件。** 单飞、等待不取消、停止不误杀和超时无旧进程四项通过，再做一个真实小 HTTP 子进程冒烟。不要因为 happy path 出图就跳过取消测试。
