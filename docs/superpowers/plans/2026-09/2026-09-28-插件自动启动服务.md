## 目标与执行边界

插件启用时复用已有 stock_robot；本机服务不可用且允许自动安装时，自举独立副本并启动。主仓将 chromadb、sentence-transformers 移入 rag extra。保留 bootstrap.py（下载、环境、配置）、launcher.py（共享任务、健康检查、进程生命周期）；client.py 保持原有 HTTP 行为。

- 主仓 D:\code\stock_robot；插件仓 D:\code\astrbot_plugin_stock_robot。分别使用各自 `.venv/Scripts/python.exe`，命令采用 PowerShell。
- 实施前核对两个仓库 AGENTS.md、Git 状态和分支，按仓库约定创建独立工作树；命令路径以实际工作树为准。
- 本计划不自动推送、合并或发布。阶段 A 必须进入实际下载的归档，才能验收纯核心安装。
- 探针、归档、日志、截图放忽略目录；失败保留诊断，凭据不提交。

## 测试预算

只新增插件 `tests/test_bootstrap.py`、`tests/test_launcher.py`；主仓回归补进已有 `tests/rag/test_cli_rag.py`。必要时修改已有 conftest，不新增 main、导入、平台或端到端专用测试文件。

## 行为约定

| 情形 | 行为 |
|---|---|
| health 成功 | 复用，不获取外部进程所有权 |
| 远程地址或 auto_install=false | 只探测，不安装，也不启动已有副本 |
| 启用、本机、允许安装 | 后台确保完整实例并启动 |
| 调用时已有准备任务 | 限时等同一任务；超时不取消后台任务 |
| 调用时无任务、已有完整副本 | 可启动或重启，不下载、不安装、不修复配置 |
| 调用时实例不完整或安装失败 | 保留原因，提示重载插件重试 |
| 自建进程存活但不健康 | 先复查；回收旧进程后才能重启 |
| 启动超时或提前退出 | 回收本次进程与日志句柄，记失败原因 |
| 停用 | 阻止新任务，取消并等待准备任务，回收安装/服务进程，再关闭 client |

端口唯一来自 base_url，不新增 startup_port。自动启动仅限回环地址、无路径前缀的 HTTP URL；远程 HTTPS/带路径 URL 仍可复用。无效配置转成可读诊断。

health 要求 HTTP 200、JSON 对象及 status=ok；任意 200 页面不算健康，此检查不是身份认证。

主仓 PowerShell：

```powershell
$probeDir = Join-Path (Get-Location) ("tmp/probe-core-" + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $probeDir | Out-Null
$archiveUrl = '填写已核实包含阶段 A 的公开归档 URL'
$downloadTime = Measure-Command {
    Invoke-WebRequest -Uri $archiveUrl -OutFile (Join-Path $probeDir 'source.zip') -TimeoutSec 300
}
$downloadTime.TotalSeconds
Get-Item -LiteralPath (Join-Path $probeDir 'source.zip') | Select-Object Length
Expand-Archive -LiteralPath (Join-Path $probeDir 'source.zip') -DestinationPath (Join-Path $probeDir 'unpacked')
$sourceDirs = @(Get-ChildItem -LiteralPath (Join-Path $probeDir 'unpacked') -Directory)
if ($sourceDirs.Count -ne 1) { throw '归档顶层结构不符合预期' }
$probeSource = $sourceDirs[0].FullName
if (-not (Test-Path -LiteralPath (Join-Path $probeSource 'pyproject.toml'))) { throw '源码缺少 pyproject.toml' }
& ./.venv/Scripts/python.exe -m venv (Join-Path $probeDir 'venv')
if ($LASTEXITCODE -ne 0) { throw '环境创建失败' }
$probePython = Join-Path $probeDir 'venv/Scripts/python.exe'
& $probePython -m pip install -e $probeSource
if ($LASTEXITCODE -ne 0) { throw '核心依赖安装失败' }
& $probePython -c "import importlib.util; print({n: importlib.util.find_spec(n) is not None for n in ('chromadb','sentence_transformers','torch')})"
if ($LASTEXITCODE -ne 0) { throw '依赖探测失败' }
```

## 阶段 C：插件实现

### 接口与所有权

产品模块使用包内相对导入，launcher 导入 .bootstrap。测试按正式包结构导入，不依赖 sys.path 插入插件目录掩盖错误。

```python
# 类型与中文注释在实现时补齐
async def download_source(archive_url, instance) -> StepResult: ...
async def make_env(instance, extras, *, runner) -> StepResult: ...
def write_config(instance, llm, port) -> StepResult: ...
async def ensure_instance(instance, archive_url, extras, llm, port, *, runner) -> StepResult: ...
def instance_ready(instance, extras) -> bool: ...

class ServiceLauncher:
    def start_background(self) -> None: ...
    async def ensure_ready(self, *, wait_timeout: float) -> ReadyOutcome: ...
    async def stop(self) -> None: ...
```

launcher 持有唯一准备任务和进程句柄，main 不持有第二个任务。状态 idle/starting/ready/failed/stopped。任务创建用短临界区，下载/安装/轮询不持有等待锁。安装失败保留原因至重载；完整副本服务崩溃可在后续调用重启。

### Task C2：共享任务与生命周期

文件：launcher.py、tests/test_launcher.py。

- [ ] 测试先行落实行为矩阵；health 单次超时也受调用等待总预算约束。
- [ ] 先复用；远程或关闭开关失败直接返回，已有入口不能绕过开关。
- [ ] start_background 仅创建一个启用任务，重复调用不重复安装/启动。
- [ ] ensure_ready 用 asyncio.wait_for(asyncio.shield(task), wait_timeout) 限时加入；预算含探测、获取和等待。调用超时不改后台状态、不取消任务。
- [ ] 无共享任务时仅启动完整副本；安装失败/不完整复用诊断，不触发 ensure_instance。
- [ ] 旧自建进程存活先复查，需替换则先结束并 await；禁止覆盖存活引用。
- [ ] 启动轮询用局部引用；进程创建期间取消也须取得创建结果并回收，避免尚未登记的孤儿进程。
- [ ] 退出、超时、异常回收本次进程和日志，记原因；观察后台结果/异常，捕获具体边界异常，不吞 CancelledError。
- [ ] stop 先标 stopped，取消并 await 准备任务，确认安装命令退出后回收服务。先 terminate，等 5 秒后 kill；重复 stop 幂等，清理失败保留句柄与诊断。

main 挂钩断言并入本文件，用最小 AstrBot 假件或适配函数覆盖。只保留一个真实小型本地 HTTP 子进程冒烟场景，用动态空闲端口、截止时间轮询、finally 回收；不用固定 25999 和 sleep(1)。复用场景断言 stop 后外部进程仍存活。
