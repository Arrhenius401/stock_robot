# 策略指数公开官方估值设计

日期：2026-10-02。状态：已实施；用户确认只使用公开官方数据。

实施计划及验收：[公开官方估值实施计划](../../plans/2026-10/2026-10-02-strategy-index-valuation-plan.md)。后续缓存提效见 [指数数据接入提效设计](2026-10-02-index-data-efficiency-design.md)。

## 问题与目标

策略指数采集原先没有设置 valuation_data，导致报告估值栏不可用。补齐可核验的官方 PE、PB、日期、来源及样本覆盖，保留未披露字段的真实缺失状态；不依赖理杏仁或 Tushare 付费权限。

## 官方数据与口径

- 中证 `perf/index-perf` 的实际行情行包含 `peg`，官网口径为滚动市盈率。`indexCsiDsPe` 会填充非交易日及查询起点占位，不能用于扩大样本。
- 中证 indicator XLS 只有近期 PE 和股息率，没有 PB；旧 AkShare 历史估值接口不可用。
- 官方 PDF 单张提供月末估值快照；国证 980092 的 PE 未声明 TTM，必须单列。932365 单张估值可能为 `--`，不得补零。
- 000015、000922 可从官方每日估值表按精确名称匹配当前 PB。其余策略指数使用可验证的月末单张 PB。
- 未取得可靠公开 PB 日频历史，PB 历史分位保持不可用。月度快照不得扩充日频样本。

## 历史样本与快照校验

PE 查询近五个日历年，按实际交易日排序去重；拒绝错误代码、未来日期、非交易日、无效收盘价及非正或非有限 PE。保留最新交易日 PE 缺失，不回填为前一日数值。

至少 252 个有效样本且最新行情距目标日期不超过 14 天，才计算当前 PE 分位。成立不足五年的指数显示真实样本数量和起止日期，不能声称完整五年覆盖。

单张必须明确匹配指数代码字段和报告日期；月度单张最多 62 天，每日 PB 最多 14 天。PDF 使用布局文本解析，拒绝错列、错码、未来或过期日期。

## 模型与采集集成

`IndexValuationData` 增加各指标日期、口径、来源链接、有效样本数量、单张 PE 和缺失说明，字段默认兼容旧报告。`StrategyValuationProvider` 按来源隔离失败，接入策略采集进度；宽基采集逻辑保持兼容。

本阶段采用整份模型缓存，任一来源失败使用短缓存；后续按来源缓存和共享历史的修正属于指数数据接入提效设计，不能将后续状态追记成该阶段原始实现。

## 展示与失败行为

部分指标可用时报告为 partial；无 PE 分位时不生成高低估标签。Web 与 Markdown 保留中文口径、日期、来源、样本和不可用原因；Web 官方来源使用安全 HTTPS 短链接，完整 URL 保留在 href、title 和 Markdown。

旧报告不自动重算，重新分析生成补齐后的结果。单张、历史或每日 PB 超时独立降级，不能用股息率或现金流收益率替代 PE/PB。

## 验收要求

回归覆盖真实日期范围、252 日门槛、错码 PDF、缺失布局、来源口径和部分可用报告。真实 Web 分别分析 515300 与 980092，核验下载内容和宽窄屏；具体实测、失败清单与复核范围并入实施计划。
