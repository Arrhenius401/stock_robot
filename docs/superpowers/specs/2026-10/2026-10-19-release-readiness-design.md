# 主仓发版完善与统一元信息

用户于 2026-10-19 确认聊天中完整方案。范围仅主仓，不发布、不推送、不变更线上或插件。

## 行为与边界

- `src/stock_robot/metadata.py` 为应用发布版本及公共名称的唯一手工入口，无第三方导入；setuptools 动态读取版本，CLI、API、MCP、回测清单引用同一值。协议版本、策略版本、数据 schema 与前端资源缓存版本保持独立。
- 默认监听配置沿用 `utils/config.py`；CLI 的回退与帮助文案引用现有默认配置，显式 CLI 参数 > 用户配置 > 默认值，不覆盖用户配置。
- 源码 Git archive、sdist、wheel 均须含模板、静态资源、分析 YAML、根目录 config/data 与采集启动所需脚本。根资源由构建过程从原目录复制，不维护第二份手工数据。
- 源码运行继续使用原目录；wheel 通过统一只读资源根入口定位随包资源。用户 `.stock_robot`、报告与已有配置不迁移，安装模式下可写映射使用当前工作目录的状态目录，不写 site-packages。
- 更新日志覆盖 v0.1.0 后的报告、数据透明度、快照、港股及兼容修复；提供手动升级备份、安装、验证和回退说明。

## 验证

先新增测试复现版本不一致和资源缺失，再修改。检查源码/安装模式路径、独立版本覆写、CLI 配置优先级、构建元数据和资源完整性；从 sdist 重建 wheel，并在非仓库工作目录执行安装后 CLI、模板、映射和 API 冒烟，避免 editable 泄漏。

最后独立规格和质量审查，按影响范围修复并复核，发布前执行全量 Ruff/Pyright/pytest。源码服务与浏览器验收按项目真实启动规范执行，不能把 Mock 或导入成功当作真实功能验收。
