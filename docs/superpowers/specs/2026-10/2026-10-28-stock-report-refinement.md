# 个股报告内容与展示收敛设计

## 状态与授权

2026-10-28 用户逐项确认 Markdown 内容，并确认本地网页预览。以本文件记录本次独立项目，不追加已交付的10月8日研报实用性历史项目。预览位于主仓 tmp/acceptance/stock-report-preview/，正文示例未调用模型。

## 已确认范围

- 定位中长期跟踪，兼容波段参考。章节：基础概况、五维量化数据、综合评分、综合研判、数据覆盖与时效、免责声明。
- 综合研判使用原有单次 AI 调用，输出核心判断、关键依据与分歧、后续观察重点三部分。围绕关键矛盾组织，引用事实、解释分歧、区分未知，不机械复述五维分数，不固定输出多风格或新增评级。
- 程序模型信号放在解读之后，仅保留名称和真实配置下的生成依据；删除操作文案、仓位数值、期限、触发与失效说明。港股信号不适用，数据不足时说明不能生成。
- 未启用、未配置或失败时提供标明状态的确定性量化摘要；数据不足不生成模型结论，重试/配置入口和会话绑定保持原行为。
- 删除逐期 ROE 表，但原始历史财报和程序经营趋势不删除。取消待验证事项展示，采集失败/不足/过期缓存/备用源切换/历史参考限制仍直接展示。
- 财务长口径移到表下；无内容限制行隐藏。PS 缺失提示不重复；PE静态展示名为PE（静），无真实数据不增加采集或填造。
- 同行空说明列按整表是否有内容决定隐藏；报告期间不重复；统计规则合并；行业评分依据在综合评分中集中展示。评分明细只清理重复折算文字，不改取值和得分。
- 数据覆盖用五行汇总表加按维度说明的异常/限制，不附完整旧表。正常元数据不重复铺陈；异常原因未知时如实标为未记录。
- Markdown 不包含 HTML 折叠标签；网页新闻使用原生 details 默认折叠，来源可点击。兼容标准角括号 Markdown 链接，继续转义外部 HTML/危险链接。
- 复用现有主题、卡片和内容区规则。报告页、会话抽屉与报告库共用渲染器同步。旧归档原文不批量改写，仍能查看原文，旧解读内容不丢失。

## 不变量及边界

不改变财报、采集范围、请求数量、评分公式、权重、分位算法、交易回测契约、信号阈值、依赖、插件版本或发布状态。历史分位数据源探测搁置；只说明现有实际窗口及派生性质，不把短期窗口称为上市以来。

A股和港股共用展示修改；港股原币/HSICS/不提供信号约束保留，指数和黄金原有专用报告不改。原始指标、score_detail、data_quality.fields保留供程序/存档追溯，精简通过展示副本实现。

## 已核实接口事实

ReportBuilder.build 使用 report_v2.jinja2；CLI/API 共享 build_report，结构化输出另由 build_stock_payload 组装。signal.py 为回测契约，报告应生成无 action/position 的信号展示。舆情计分状态和待验证数据已动态生成，无需新造机制。AI主动关闭目前没有量化摘要，需要统一降级。网页 markdown.js 整体转义输入，不支持原始 details；应由 DOM 控件折叠新闻，支持安全的角括号链接语法。

先写章节顺序、信号真实阈值、降级、无逐期ROE、无空/重复字段、质量异常保留和三段提示词回归。DOM回归覆盖旧快照、只读、重试、新闻链接与HTML注入。相关 Ruff/Pyright/pytest；不默认Full。真实 .venv stock-robot.exe run 启动8765，浏览器真实发送并收到报告；检查报告页/报告库/抽屉和390px展示，保留样例与日志在tmp。真实付费AI调用不增加，未实测模型生成质量如实列限制。S级规格与质量双审查、复核后同事项一笔中文本地提交，不推送合并发布。
