# 跨市场数据补全总体设计（个股与指数，A 股/港股/美股）

日期：2026-11-18。状态：总方向已确认；A 股指数估值/资金口径已确认，港美各阶段先探针后实施。

## 1. 状态与授权

2026-11-18 用户确认：

- 数据补全合并为一个三市场总计划，不再只做 A 股。
- A 股指数先做：当前官方 PE/PB/股息快照 + 沪深融资余额市场背景。
- 港股/美股继续处理：个股财务深度、估值历史、指数估值/HSTECH PE。
- 融资余额是 A 股专用市场背景，不套到港股/美股。
- 所有补全只改数据与展示，不改评分、信号、权重或历史报告。

本文覆盖个股与指数，A 股/港股/美股。批量比较、雷达、推送、插件不在范围内。

## 2. 数据状态与时效口径

### 2.1 状态

| 状态 | 含义 | 报告处理 |
|---|---|---|
| `available` | 当前有效 | 正常展示 |
| `partial` | 有数据但覆盖/字段/期间不完整 | 展示可用事实，列限制 |
| `stale` | 有数据但超过时效 | 保留原日期展示，不冒充当前 |
| `not_collected` | 本期未采集 | 明确“未采集”，不写成零风险 |
| `not_supported` | 有概念但无可靠来源 | 明确“未支持”，不硬补 |
| `not_applicable` | 市场/风格不适用 | 说明原因，不计入缺口 |

数据质量表继续使用现有四状态（ok/partial/unavailable/not_applicable）；`stale`、`not_collected`、`not_supported` 的原因写入“分析限制”。

### 2.2 时效

- 行情日线：超过 7 个自然日未见新交易日 → `stale`（长假除外，按市场日历）。
- 当前报价：超过 14 天、早于日线或未来 → 回退收盘并说明。
- 个股估值快照：超过 14 天 → `stale`。
- 个股财报：超过正常披露窗口（季报约 120 天、半年报约 180 天、年报约 180 天）→ `stale`；具体以来源报告期为准。
- 指数官方 PE/PB：月末/月频快照超过 62 天 → `stale`。
- 指数融资余额：超过 7 天 → `partial`；超过 14 天 → `unavailable`。
- 宏观：CPI/PMI 超过 90 天、10Y 超过 14 天、HIBOR 超过 10 天 → `stale`。
- 新闻：只保留近 30 天；无有效日期不归为当日。
- 行业映射/策略权重：展示快照日期；权重超过 45 天标 `partial`。

所有带日期的数据必须保留 `as_of`/`data_date`；不得用采集时间代替数据日期。

## 4. 工作流

### 4.1 Phase 1：A 股指数估值与资金（已确认）

#### 估值

- 只补 `indexValuation` 覆盖的 8 个名称：上证指数、上证180、上证50、沪深300、上证380、红利指数、中证红利、中证500。
- 当前目录实际只有 000001、000016、000300、000905、000922；000009/000010/000015 不自动新增目录。
- 使用 `pe/pb/dp` 当前快照；`pe` 标“官方当前PE（来源字段pe，口径未声明）”；不称 TTM。
- 不设置 `pe_ttm`/`pe_percentile`/`pb_percentile`；不使用 `peg`。
- 801780、930740 估值保持现状。

#### 资金

- 不再使用北向；改用上交所 + 深交所官方融资余额。
- 以最近行情日为锚，向前最多 7 个自然日找沪深共同交易日。
- 上交所融资余额元 ÷ 1e8；深交所已是亿元；合计为亿元。
- 展示“A 股融资余额（沪深合计）为 X 亿元（截至 DATE），较前一交易日变化 Y 亿元；余额指标，不代表指数净流入或行业资金流”。
- 宽基和行业都显示；行业注明“全 A 市场背景，不是行业资金流”。
- 策略指数资金仍不适用。

### 4.2 Phase 2：港股/美股个股财务深度

目标：把“有报告但没有可比口径”的财务事实补到可用，不强行造 TTM。

#### 港股

探针项：

- 东方财富港股 F10 三表能否稳定提供半年度/年度收入、净利润、权益、经营现金流、币种；
- 能否从累计期间安全推导 TTM；如果无法同时确认期间和币种，不推导；
- 现金流缺失时保留缺失，不用利润替代；
- 金融股专项指标是否可用。

设计倾向：

- 优先补币种、金额口径、现金流期间；
- TTM 只在“同期、同币种、连续期间”可核实时计算；
- 否则继续报告期口径，明确“不转 TTM”。

#### 美股

探针项：

- 资产负债表最近可得期为什么落后于利润表（AAPL 2026-09-26 vs 2025-12-27）；
- 能否从同源 F10 补齐最近季度资产负债表；
- 银行/保险专项指标（BMAIN）能否进入财务展示但不计分；
- BRK.B 收入映射是否可以证实；不能则保持 N/A。

设计倾向：

- 资产负债表优先补最近季度；补不到就保留“最近可得”并标日期；
- 银行/保险只补事实，不接入通用财务评分；
- 不用 PE/PB 反推 ROE 或营收。

### 4.3 Phase 3：港股/美股估值历史

现状：港股/美股个股估值历史只使用近一年百度曲线（cutoff 365 天），只能算一年分位；A 股有更长窗口。

探针项：

- 百度估值接口是否支持更长区间或分页；
- 东财/F10 是否提供可核实的 PE/PB 历史；
- 港股官方/交易所是否提供估值历史；
- 能否保持同一来源、同一口径连续序列。

设计倾向：

- 只有同一来源、同一口径、至少 252 个有效交易日，才计算分位；
- 不能拼接不同来源或不同窗口；
- 找不到 5 年源时，保留一年分位并标“近一年”，不冒充长期分位；
- 不把价格分位当估值分位。

### 4.4 Phase 4：美股指数估值 / HSTECH PE / 港股指数缺口

#### 美股指数估值

- 当前 `_fetch_index_valuation` 对 `overseas` 明确未支持。
- 探针官方 S&P/Nasdaq 估值文件、东财/F10 或其他可核实来源；找不到就保持 `not_supported`。
- 不把 PE/PB 快照拼成历史分位。

#### HSTECH 官方 PE

- 当前源返回非 XLSX；HSI PE 正常（2026-10-30 为 13.04）。
- 探针恒生官方 HSTECH 估值文件路径/格式；修正后保留月末快照和日期。
- 找不到有效 XLSX 时保持不可用，并保留具体原因。

#### 港股指数 OHLC

- HSTECH 目前只有收盘价，ADX/ATR/价格位置缺失。
- 探针东财/腾讯港股指数 OHLC 是否与官方收盘一致；验证后才补技术指标。
- 不把收盘价拼接成 OHLC。

#### 其他

- 美股指数宏观继续只展示 CPI/10Y；过期 ISM/美联储/失业率不进当前结论。
- 港股/美股指数新闻继续是市场新闻，不做指数专属推断。

### 4.5 探针结论与实施批次

2026-11-18 只读探针结论：

- 美股 F10 直接读取资产负债表时，6/6 样本可取得与利润表同报告期的资产负债表；现包装的 Q1–Q4 过滤是滞后原因。
- JPM BMAIN Q9 金额/比例/百分数单位已核对；只展示事实，不接入评分。
- BRK.B 的 F10 收入总额包含投资收益，与发行人 10-Q 的 Total revenues 不一致；保持 N/A。
- AAPL 五年估值 1,253 个有效交易日；00700 三年 737 个，五年只有 618 个且抽样，不能称完整五年。
- HSTECH 腾讯 200 条收盘与恒生官方 200/200 一致，高低边界通过；可作技术指标候选，官方收盘仍作价格身份。
- HSTECH 官方 PE 是 HTML/404，不是坏 XLSX；美股指数 PE/PB 无可靠源。

实施批次：

**Batch A（直接实施）**

- 美股资产负债表改用同源 F10 直取，不按 `单季报` 过滤；
- JPM 银行专项事实展示；BRK.B 收入保持 N/A；
- 不改评分/信号。

**Batch B（有验证门禁）**

- AAPL 五年估值：同源同口径、至少 252 个有效交易日；长窗异常/修订/口径稳定性验证后接入；
- 00700 三年估值：需收盘后复验同日值和采样规则；五年保持 `not_supported`；
- HSTECH 腾讯 OHLC：仅补 open/high/low 给技术指标，收盘用恒生官方；收盘容差、长期断档、失败回退验证后接入。

**Batch C（条件实施）**

- 港股财务币种/期间：只有同报告期、同币种、连续期间可核实时才补 TTM；
- 现金流缺失保持缺失；不能用利润替代；
- 00700 三年估值与 Batch B 共用窗口规则。

**继续不可用**

- BRK.B 收入映射；
- HSTECH 官方 PE；
- 美股指数 PE/PB；
- 未覆盖指数的估值。

## 5. 数据合同

- 每个事实必须有 `source`、`as_of`/`data_date`、单位、期间/币种。
- 不混用不同来源、不同期间、不同币种。
- 缺失保持 None/空，不补零、不用相似字段替代。
- 数据补全不改变评分、信号、覆盖率和历史报告。
- 报告与模型只消费同一事实对象；模型不能补造数值。

## 6. 兼容与降级

- 新字段有默认值，旧快照可读。
- 旧报告保留原北向/旧估值文案。
- 新报告不展示已判定不可用的北向、`peg` 历史 PE。
- 数据源失败保留旧成功缓存和原日期，不冒充当前。
- 未覆盖指数/个股保持原状态。

## 7. 验收

- Phase 1：000300 当前 PE/PB/股息率 + 融资余额；801780 资金为全市场背景；930740 资金不适用；HSTECH 仍南向。
- Phase 2：港股 TTM/币种/现金流有明确可用或不可用状态；美股资产负债表日期改善或明确滞后；银行/保险只补事实不改分。
- Phase 3：港美估值历史长度、来源、有效样本明确；没有 5 年源时标“近一年”。
- Phase 4：美股指数估值/HSTECH PE 有源则补，无源则 `not_supported`；HSTECH OHLC 验证后才补技术指标。
- 旧报告库、下载、390px 正常。

## 8. 顺序与风险

建议顺序：Phase 1 → Phase 2 → Phase 3 → Phase 4。

- Phase 1 已有明确源，先交付。
- Phase 2/3/4 先探针，探针失败就明确不可用，不阻塞其他阶段。
- 港美财务和估值历史可能无法达到 A 股口径；必须保留差异，不强行统一。
- 不默认运行全量门禁；合并/发布前再 Full。
