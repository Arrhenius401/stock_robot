# 个股数据缺失全量解决设计（A 股/港股/美股）

日期：2026-11-24。状态：设计已确认，待编写实施计划并交由 Codex 实施。

关联文档：

- `docs/superpowers/specs/2026-11/2026-11-18-跨市场数据补全总体设计.md`
- `docs/superpowers/plans/2026-11/2026-11-18-跨市场数据补全实施计划.md`

本文是个股数据缺失的新独立事项，不追加到 2026-11-18 指数与个股混合项目的历史文档中；只引用其已确认口径。

## 1. 背景与目标

2026-11-24 只读排查确认，个股报告仍存在以下缺口：

- A 股：PS(TTM) 全市场缺失；估值快照单源；行情窗口约 168 个交易日；同行市值排名因个别缺市值整项暂缺；行业同行池单源。
- 港股：财报金额币种/单位未核实，TTM、ROE、跨期金额比较受限；估值历史仅百度近一年，三年仅 00700；PS 单源。
- 美股：估值长窗仅 AAPL；BRK.B 收入 N/A；银行/保险通用指标不适用；行业经营营收未核实；新上市标的多维缺失。

本次目标：在“可补尽补 + 无源明示”的口径下，解决全部可验证的个股数据缺口；不能证明来源、期间、币种、单位或口径的，继续保持明确不可用，不补零、不猜测、不用相似字段替代。

范围：A 股、港股、美股个股报告。非目标：指数、雷达、推送、黄金、RAG、AstrBot 插件、历史报告重写、付费数据源、登录态数据源、招股书/上市文件提取。

## 2. 已确认决策

1. **解决口径**：可补尽补 + 无源明示。只有免费公开源且能证明同源、同期间、同币种/单位的才补；证明不了保持 `not_supported`。
2. **增源授权**：允许新增免费公开数据源并按只读探针验证；不引入付费 API、不绕过登录。
3. **舆情口径**：保持 LLM 标注依赖；未配置模型或无有效样本时明确“无法评估/不计分”，不新增规则情绪或第二模型。
4. **评分影响**：评分公式、权重、阈值不变；新数据更完整可以自然改变新报告的评分/信号；旧报告不重写。
5. **短历史标的**：事实报告 + 完整原因，不追补招股书或二手数据。
6. **交付方式**：Codex 在独立工作树实现；Claude 做规格/质量审查与真实样本验收；通过后本地合入 dev；不推送、不发版、不改写历史报告。
7. **A 股行业同行池**：用户确认接受乐咕精确申万三级单源 + 已验证缓存兜底；本轮不新增第二 SW3 源，不降级到申万一级/二级或东财行业冒充同行池。

## 3. 统一数据合同

所有新增事实必须带以下元数据，缺一项不得进入评分证据：

- `source`：明确来源名称与接口/文件身份。
- `as_of` 或数据日期：不得用采集时间代替数据日期。
- `unit`：货币单位或比例单位。
- `currency`：金额类字段必须明确；不能证明时留空并说明。
- `period`：报告期起止、单季/累计/TTM。
- `basis`：定义口径，例如“官方当前 PE（来源字段 pe，口径未声明）”“SEC XBRL 营业收入（不含投资损益）”。

统一原则：

- 不混用不同来源、不同期间、不同币种。
- 缺失保持 `None`/空，不补零、不用相似字段替代。
- 新增源失败保留旧成功缓存和原日期，不冒充当前。
- 旧报告与旧快照保持可读；新增字段有默认值。
- `not_supported` 表示“无可靠源或证据不足”，`unavailable` 表示“本次采集失败”；两者都不得写成零风险。

## 5. 分市场设计

### 5.1 A 股

#### 5.1.1 估值快照

取值链：

1. 腾讯 `qt.gtimg.cn` 当前快照（PE/PB）。
2. 腾讯失败时，取东财日频估值最新一行（PE/PB/PS/总市值/总股本/日期）。
3. 东财也失败时，取百度曲线末值（PE/PB，日期来自曲线）。
4. 全部失败：估值维度 `unavailable`，原因写明每个来源的失败。

要求：

- 快照值、日期、来源必须成组保留，不得把不同日期拼成同日。
- 腾讯成功时仍以腾讯为当前快照；东财历史只用于历史分位和 PS，不覆盖腾讯快照。
- 百度回退的末值标“百度曲线末值（非实时快照）”。

#### 5.1.2 估值历史与 PS

- 新增东财 `stock_value_em` 日频历史作为 A 股估值历史主源：
  - 字段：日期、PE(TTM)、市净率、市销率、总市值、总股本。
  - 默认窗口近五年；可按实际可用样本缩短，但必须显示真实起止日期和样本数。
  - 每个指标至少 252 个有效样本才计算历史分位；不足则显示样本数，不计算分位。
- 百度近一年历史保留为备源：
  - 各指标至少 120 个有效样本才计算分位；标签固定“近一年”，不得冒充长期分位。
- 分位参照值必须来自计算分位的同一历史源末值；与当前快照来源或日期不同时分别标注，不能把快照数值与历史曲线参照值说成同一时点数据。
- 东财与百度历史都不可用时，保留现有“行情+财报”派生估值路径；标“派生，仅参考”，分位阈值沿用 120，不冒充实测估值。
- PS(TTM)：
  - 优先使用东财日频最新“市销率”，标“东财日频估值-市销率（口径未声明）”，只展示、不计分。
  - 东财 PS 缺失但 TTM 营收、总市值/总股本可核实时，可派生 PS，标“市值 ÷ 同报告期 TTM 营收（派生）”并给出日期。
  - 两者都不可用：PS 显示缺失原因，不填零。
- 总股本/市值：
  - 优先使用东财日频同一行的总股本/总市值。
  - 东财不可用时保留现有腾讯 PE/PB 反推与财报反推链。

#### 5.1.3 行情窗口

- A 股默认行情窗口从 250 个自然日调整为 365 个自然日，与港股、美股一致。
- 技术指标、价格位置、派生估值继续按实际取得的交易日计算。
- 报告中的“采集区间”“样本数”“价格位置”显示真实区间；不得用“近一年”掩盖不足一年的样本。

#### 5.1.4 同行市值排名

- 改为部分覆盖：
  - `rank = 1 + 同日有效同行中市值严格高于目标的家数`；并列市值共享同一名次，不按顺序拆名次。
  - `total`：参与排名的同日有效市值同行数（含目标）。
  - `pool_total`：同行池总数。
  - `coverage`：`total/pool_total`。
- 缺失记录、日期不一致或市值非正的同行从排名中剔除，但计入 `coverage` 缺口；不得因个别同行缺失而拒绝整项排名。
- 仅以下情况返回无排名并写明原因：同行池重复代码、同行数据含未知代码、目标市值缺失或日期无效、目标日期与快照日期不一致、目标日期在未来、没有任何同日有效同行。
- 展示“在 N 家同日有效市值同行中排名 X（池共 M 家）”；部分覆盖时注明 `total/pool_total`。
- 排名只用于展示，不参与评分。

#### 5.1.5 行业同行池

- 继续只接受精确申万三级同行池，不符合者不降级到申万一级/二级或东财行业。
- 乐咕为唯一已验证分类源；已有成功缓存时作为“旧快照”兜底，展示分类快照日期。
- 当前 `sw_index_third_cons` 不可用，不接入；如 Phase 0 找到可核实的第二 SW3 成分源，必须提供同一行业代码、同一成分身份与日期，才可接入；否则无缓存时明示不可用。
- 同行财务与估值比较继续按同日、同期间、同币种规则；至少 5 家有效同行才计算中位数/分位。

#### 5.1.6 财务可选字段

- 资本开支、自由现金流、经营现金流继续按同花顺同源披露；接口失败保持缺失并说明。
- 不用利润、营收或其他报表字段替代现金流。
- 财务包缺项继续按现有 `package_complete` 门禁降为 partial，不强行补全。

#### 5.1.7 舆情

- 保持 LLM 标注依赖；未配置模型、无有效样本或标注失败时明确显示“无法评估/不计分”。
- 新闻与公告采集、去重、相关性过滤和样本列表保持现有行为。
- 不新增规则情绪评分。

### 5.2 港股

#### 5.2.1 币种/单位证据

新增逐期证据适配器：

- 数据来自东财港股分析指标接口（akshare `stock_financial_hk_analysis_indicator_em` 同源），字段：
  - `REPORT_DATE`、`START_DATE`、`CURRENCY`、`IS_CNY_CODE`。
  - `OPERATE_INCOME`、`HOLDER_PROFIT`、`ROE_AVG`。
- 普通企业模板核验：
  - 报表 `004001001`（营业额）+ `004001002`（其他营业收入）必须等于指标 `OPERATE_INCOME`。
  - 报表 `004025002`（净利润）必须等于指标 `HOLDER_PROFIT`。
- 银行模板核验：
  - 按现有银行科目映射（`001003999` 收入、`001025002` 利润等）与指标接口逐项核对；Phase 2 先探针确认映射，再写死测试。
- 期间起点必须一致；金额按最小货币单位或 0.01% 容差校验；币种必须一致；`IS_CNY_CODE` 与 `CURRENCY` 不矛盾。
- 只有核验通过的期间才设置：
  - `amount_currency_verified=True`
  - `report_currency=接口 CURRENCY`
  - 金额单位按接口口径（基本货币单位）。
- 任一期间未通过：该期保持未核实，不生成 TTM。

#### 5.2.2 TTM、ROE 与现金流

- TTM 计算口径沿用现有 `financial_ttm` 的同期对齐规则：最新期为年报时直接使用该期；否则“最新期 + 上年年报 + 上年同期”三期均须通过币种/单位核验后才计算。
- ROE：
  - TTM 与权益证据链通过时，按现有“TTM 归母净利润 / 期末归母权益”计算。
  - TTM 不通过时，可展示指标接口的年度 `ROE_AVG`，标“披露年度 ROE（分析指标接口，年度，未年化）”，仅展示、不进入 TTM 评分链。
- 现金流：
  - 币种/期间与利润表证据一致时允许 TTM；否则保持缺失。
  - 不用利润替代现金流，不补零。

#### 5.2.3 估值历史

- 百度近三年从只支持 00700 扩展到全部港股。
- 接入条件：
  - 与近一年曲线共同日期零冲突。
  - 逐指标至少 252 个有效样本。
  - 来源、窗口、起止日期、样本数写入报告。
- 近五年保持 `not_supported`，原因写明“百度五年曲线抽样/共同日期不足，不能称完整五年”。
- PS 继续只使用东财估值对比的当前值；无 PS 历史不伪造。

#### 5.2.4 行业、新闻与主营

- 行业只覆盖港股通与恒生 HSICS；非港股通、映射缺失保持现有明确状态。
- 新闻继续关键词检索；部分查询失败、达到 100 条上限、0 条结果分别说明。
- 舆情继续依赖 LLM；未配置或 0 条有效评估时明确不计分。
- 主营资料继续 F10；失败保持不可用原因。

### 5.3 美股

#### 5.3.1 估值历史

- 百度近五年从只支持 AAPL 扩展到全部美股。
- 接入条件：
  - 与近一年曲线共同日期零冲突。
  - 逐指标至少 252 个有效样本。
  - 窗口、起止日期、样本数、来源写入报告。
- 失败时回退近一年，保留失败原因；不得把五年标签用在样本不足的曲线上。
- PS：
  - 继续使用“总市值快照 ÷ 已核实 USD 的 TTM 营收”派生；条件不满足时缺失并说明。
  - BRK.B 如使用 SEC 营业收入派生 PS，必须标明口径，不冒充 F10 营业总收入。

#### 5.3.2 资产负债表

- 维持“同报告期优先”：
  - 利润表报告期存在同期资产负债表时，直接使用。
  - 不存在时使用最近可得期，并在字段来源、财务包说明和报告数据质量中显示“资产负债表最近可得 YYYY-MM-DD”。
- 增加 AAPL、MSFT、NVDA、COST、JPM 的真实数据回归，确认同期数据存在时不再回退旧期。
- 币种、会计准则、期间缺失时保持 partial，不推断。

#### 5.3.3 BRK.B 收入

- 新增 SEC XBRL 适配：
  - 使用 `RevenueFromContractWithCustomerExcludingAssessedTax`。
  - 定义：“营业收入（不含投资损益）”，USD。
  - 单季值由累计值差额推导：H1−Q1、9M−H1、FY−9M。
  - 每期带 10-Q/10-K、filed 日期、期间起止、单位。
- 只作为展示事实进入财务表与 PS 说明，不接入通用财务评分。
- SEC 数据缺失、与 10-Q 对账失败或概念不完整时保持 N/A，原因写明“SEC 营业收入未取得或未对账通过”。
- 不使用 F10 总收入或投资损益口径替代。

#### 5.3.4 行业经营比较

- Phase 0 用 SEC XBRL 校验东财 F10 `OPERATE_INCOME`：
  - 样本至少 AAPL、MSFT、NVDA、JPM、COST。
  - 校验身份、期间、币种（USD）、金额与定义。
- 通过后登记为已审核营收协议，允许行业经营比较使用 F10 营收；失败继续保持 `revenue_verified=False`、经营指标不计分。
- 行业同行估值仍要求已审核 PE/PB/市值协议；不足 5 家有效同行时不计算中位数/分位。
- BRK.B 不进入通用经营比较，继续单独事实展示。

#### 5.3.5 短历史与新上市标的

- 保持事实报告：有多少行情、财务、新闻事实就展示多少；财务/估值/行业不足时逐项写原因。
- 不追补招股书、上市文件、二手数据。
- 至少 20 条日线才计算技术指标；不足时只展示价格事实，不生成技术结论。
- 舆情继续只作新闻事实展示、不计分。

## 10. 风险与回退

- 东财/百度/SEC 限流或改版：独立缓存、断路器、失败保留旧日期数据并明示。
- 跨源数值不一致：当前快照仍以腾讯为主；历史分位只用同一来源的曲线，不拼接。
- 港股交叉核验可能因四舍五入失败：容差从严（最小货币单位或 0.01%），失败即保持 `not_supported`。
- BRK SEC 概念或期间不完整：回退 N/A，不用 F10 投资损益混入口径。
- 美股行业营收校验不通过：维持不计分，不用“看起来合理”替代。
- A 股精确申万行业第二源不可用：只保留已验证缓存兜底，不降级到其他行业分类。
- 新数据导致新报告评分变化：已获用户确认；评分公式、权重、阈值和旧报告不变。
- 性能：新增网络请求必须并发/缓存/预算受控；不在报告请求路径重复拉取全量历史。
