# 跨市场指数报告统一与综合研判改写设计

日期：2026-11-18。状态：已实施，通过本地分范围检查和真实服务验收。

## 1. 状态与授权

2026-11-18 用户确认：

- 综合研判改成股票 v2 同构结构：指数定位、核心结论、维度解读、风险提示、解读限制。
- 统一范围包含章节能力矩阵、缺口语义和 AI 解读；同时补已验证可靠的数据源。
- 数据补齐只做可靠源：美股 CPI/10Y、港美市场新闻；过期指标和不可用估值明确标注，不硬补。
- 港美指数新闻按“市场新闻 + 相关性过滤”口径，明确不等于指数专属事件。
- 历史表现/风险收益保留现有第二节，不新增 AI 维度；综合研判只引用关键数字。

本文覆盖 A 股、港股、美股的个股指数报告；批量比较表、指数目录、推送和插件不在范围内。旧报告不改写，旧三段式继续可读。

## 2. 现状

### 2.1 已统一

- Markdown 只有一份 `src/report/templates/index_report.jinja2`，网页由 `src/api/static/js/report-renderer.js` 的 `renderIndexReport` 渲染。
- 章节固定为：概览、历史表现与技术面、估值面、资金/宏观/新闻、综合研判、数据覆盖与时效、免责声明。
- 数据质量表复用个股 `compact_quality`，不生成指数加权评分或仓位系数。

### 2.2 未统一

- 综合研判仍是旧三段式：核心判断、关键依据与分歧、后续观察重点；`src/index/commentary.py` 只校验三个标题，没有程序维度短句、证据 ID、风险候选、数字校验和解读限制。
- `visible_sections`、`build_quality` 的适用性、各分析模块的“不可用”文案是三套逻辑，市场/风格差异散落。
- `IndexReport` 没有市场/风格字段，网页只能靠 `visible_sections` 和硬编码文案判断。
- 港美数据缺口：
  - 港股新闻采集直接写失败记录“未取得可靠的港股市场新闻来源”；
  - 美股不采集新闻；
  - 美股宏观返回“尚未适配当地宏观来源”；
  - 美股指数估值明确未支持；
  - HSTECH 官方 PE 源返回非 XLSX，当前不可用。

## 3. 目标与非目标

### 3.1 目标

1. 用 `IndexProfile` 统一市场 × 风格的可见章节、AI 维度和缺口语义。
2. 三市场综合研判统一为股票 v2 同构结构。
3. 补美股 CPI/10Y、港美市场新闻，明确数据日期和“市场新闻”属性。
4. 保持历史表现、估值、技术等现有事实口径和评分边界。
5. A 股现有报告正文尽量逐字不变；旧报告继续按旧三段式可读。

### 3.2 非目标

- 不新增指数加权评分、仓位系数、评级、目标价或支撑压力。
- 不把过期 ISM/美联储/失业率当当前宏观状态。
- 不硬补美股指数估值或 HSTECH 官方 PE。
- 不把市场新闻说成指数专属事件，不做情绪打分。
- 不改批量比较表、指数目录、插件和推送。
- 不改写历史归档。

## 4. 统一框架

### 4.1 IndexProfile

新增 `src/index/profile.py`，按 `market + index_style` 声明：

| 字段 | 说明 |
|---|---|
| `key` / `label` | `a-broad` / `a-sector` / `a-strategy` / `a-default` / `hk` / `us` / `overseas` |
| `market` / `style` | 原始市场与风格 |
| `sections` | 可见章节集合 |
| `dimensions` | AI 维度集合 |
| `capital_kind` | `northbound` / `southbound_background` / `none` |
| `macro_kind` | `cn` / `hk` / `us` / `none` |
| `news_kind` | `a_market` / `market_search` / `none` |
| `valuation_kind` | `index` / `hk_official` / `strategy_official` / `unsupported` |
| `placeholders` | 资金/宏观/新闻不适用或未采集的文案 |
| `limitation` | 综合研判固定限制 |

矩阵：

| 能力 | A 宽基 | A 行业 | A 策略 | 港股 | 美股/海外 |
|---|---|---|---|---|---|
| 技术 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 估值 | 官方 | 官方 | 官方专项 | HSI PE；HSTECH 暂不可用 | 未支持 |
| 资金 | 北向/主力/融资 | 北向/主力/融资 | — | 港股通市场背景 | — |
| 宏观 | 国内 | — | — | HIBOR/基本利率/总结余 | 美国 CPI + 10Y |
| 新闻 | A 股市场新闻 | A 股市场新闻 | — | 港股市场新闻 | 美股市场新闻 |
| 策略专项 | — | — | ✓ | — | — |
| 历史表现 | ✓ | ✓ | ✓ | ✓ | ✓ |

说明：

- `a-default` 承接 `index_style is None` 或未识别风格，章节集合保持现状：概览、历史表现、技术、估值、新闻；不含资金/宏观。不得回退到 `a-broad`。其 AI 维度为技术、估值、新闻；资金/宏观不适用。
- A 行业不配置国内宏观，避免用宽基环境代替行业判断。
- A 策略不适用通用资金/宏观/新闻。
- 港股通资金是市场背景，不是指数资金流。
- 美股 `us` 的 `macro_kind=us`；非美 `overseas` 的 `macro_kind=none`，不拿美国 CPI/10Y 冒充当地宏观。
- HSTECH 官方 PE 当前源不可用；美股指数估值未支持。

### 4.2 IndexResearch v2

`IndexReport` 增加 `index_research`，三市场同一结构：

```json
{
  "version": 2,
  "market": "a-shares|hk|us",
  "style": "broad|sector|strategy|overseas",
  "profile": "a-broad",
  "positioning": [
    {"label": "市场/风格", "value": "", "note": ""}
  ],
  "dimensions": [
    {"key": "index_technical", "label": "技术面", "text": "", "rule": "",
     "status": "available|partial|not_applicable|not_collected|not_supported|unavailable",
     "reason": "", "evidence_ids": ["index_technical"]}
  ],
  "evidence": {},
  "risk_candidates": [],
  "model": null,
  "limitation": ""
}
```

- `positioning` 由程序生成：市场/风格、跟踪指数/ETF、收益口径、数据区间、估值口径。
- `dimensions` 只放适用维度；不强行凑固定五维。
- `model` 只接受 `conclusion{overall,support,question}`、`evidence_ids`、`risks[]`。
- 模型不能修改程序维度短句和指数定位。

### 4.3 章节与历史表现

- 历史表现/风险收益继续放在第二节，由 `IndexPerformanceAnalyzer` 生成；不新增 AI 维度。
- 综合研判的“核心结论”可以引用近 1/3/12 月收益、最大回撤、波动率，但不重复整张表。
- 指数定位只放元数据，不放历史表现表。

### 4.4 缺口语义

内部区分：

- `available` / `partial` / `unavailable`：数据状态；
- `not_applicable`：风格不适用；
- `not_collected`：有概念但未采集；
- `not_supported`：有概念但无可靠来源。

数据质量表继续使用现有四状态，不新增 UI 状态；`not_collected`/`not_supported` 的原因写进“分析限制”。AI 解读按真实原因说话，不能把“未采集”写成“样本不足”，也不能写成零风险。

## 5. 市场与风格规则

### 5.1 A 股

- 宽基：技术、估值、资金、宏观、新闻；历史表现独立章节。
- 行业：技术、估值、资金、新闻；宏观不适用；行业资金映射未核实时不展示。
- 策略：技术、估值、策略专项；资金/宏观/新闻不适用；官方权重覆盖不足必须说明。
- 新闻是市场新闻，不等于指数专属事件；不做情绪打分。

### 5.2 港股

- 资金：港股通沪/深成交净买额，明确“市场背景，不代表指数资金流”。
- 宏观：HIBOR 1M、基本利率、总结余；标明金管局日期。
- 估值：HSI 官方月末 PE 快照，未声明 TTM，不判断历史高低估；HSTECH 源不可用时明确说明。
- 新闻：新增东方财富关键词检索，按指数名/别名和港股市场词过滤；标注“市场新闻”。
- 策略：不适用。

### 5.3 美股/海外

- 技术、估值、历史表现：沿用现有海外指数行情；估值未支持时明确“来源未核实”。
- 宏观：新增美国 CPI 年率和美国 10 年期国债收益率；只用当前有效值，标明日期。
- 新闻：新增东方财富关键词检索，按美股/指数别名过滤；标注“市场新闻”。
- 资金：不适用。
- 过期 ISM/美联储/失业率不进入当前宏观结论。

## 6. 数据补齐

### 6.0 美股指数行情解析（Phase 0 阻塞修复）

实测 AkShare 1.18.81 的 `index_global_hist_em("标普500")` 返回 10,180 行，列为 `日期/代码/名称/今开/最新价/最高/最低/振幅`。2026-11-17 行：开盘 7411.02、最新价 7340.53、最高 7415.37、最低 7288.34。同日新浪 `.INX`：open 7411.02、high 7415.3701、low 7288.3398、close 7340.5298。两者开盘一致，高、低、收盘按两位小数舍入后一致，确认：

- `今开` 是当日开盘；
- `最新价` 是历史收盘，不是实时价；
- `最高/最低` 是当日高低。

设计：

- `_fetch_index_price` 的 open 别名增加 `今开`，close 别名增加 `最新价`，仅用于历史行情接口；
- 主源非空但解析后 0 行时，触发新浪 `.INX` 回退，不把“非空表”当成成功；
- SPX 基线使用东方财富主源，来源标“东方财富全球指数历史”，不用新浪直接替代；
- 注释记录同日对照与两位小数舍入，避免后续误判为不同口径。

### 6.1 美股宏观

探针结果（2026-11-18）：

- `macro_usa_cpi_yoy`：225 行；最新有效值 2026-09 为 3.7%，发布日 2026-10-14；2026-10 现值仍为 NaN。
- `bond_zh_us_rate`：最新 2026-11-17，美国 10 年期国债收益率 5.1%。
- `macro_usa_ism_pmi` 最新 2025-09-02 48.7；`macro_bank_usa_interest_rate` 最新 2025-07-31 4.5%；`macro_usa_unemployment_rate` 最新 2025-09-05 今值 NaN。三者已过期，不作为当前宏观。

设计：

- `MacroContext` 增加 `us_cpi_yoy`、`us_10y_yield`。
- `_fetch_index_macro` 增加 `market` 参数；美股分支调用 `macro_usa_cpi_yoy` 和 `bond_zh_us_rate`。
- CPI 取最新非空 `现值`，日期用 `时间`；发布日写 `indicator_dates`。
- 10Y 取最新非空 `美国国债收益率10年`，日期用 `日期`。
- 数据超过合理期限（CPI > 90 天、10Y > 14 天）标为过期/部分可用，不冒充当前。
- `MacroAnalyzer` 美股分支输出“美国CPI年率、美国10年期国债收益率”；不输出国内 PMI/Shibor。
- `presentation.LABELS`、`display_rows`、`build_quality` 同步新字段。

### 6.2 港美指数新闻

探针结果：

- 东方财富关键词检索对 `恒生科技指数`、`标普500`、`纳斯达克指数` 均返回 100 条。
- 结果混合 ETF/基金广告和非指数新闻，需要严格过滤；只能作为市场新闻。

设计：

- 新增 `src/index/index_news.py`：
  - 复用 `data.hk_news.search_news`，单关键词单请求，超时 12 秒，不翻页。
  - 关键词：指数名称、简称、别名；美股补充“美股/标普/纳指/道指”等市场词，港股补充“港股/恒生/恒科”。
  - 过滤：标题必须命中指数别名或市场词；剔除含“ETF/基金/联接/净值/标的指数”等广告特征；剔除无标题/无链接/日期无效；按标题和链接去重；最多 10 条。
  - 输出 `title`、`source`、`published_at`、`url`，并附“市场新闻，不等于指数专属事件”的说明。
- `AkShareAdapter._fetch_index_sentiment` 增加 `market`/`name` 参数；A 股保留现有市场要闻；港股/美股走新适配器。
- `IndexDataCollector` 为港股/美股增加新闻采集步骤，删除港股固定失败记录。
- `IndexSentimentAnalyzer` 摘要改为“本次取得市场新闻 N 条；市场新闻，不等于指数专属事件；未作情绪评分”。
- `IndexProfile` 的 `news_kind` 驱动是否采集和占位文案。

### 6.3 明确不可用

- 美股指数估值：`_fetch_index_valuation` 对 `overseas` 明确未支持；不硬补。
- HSTECH 官方 PE：请求返回“不是 XLSX”；保持不可用，并在估值区说明源不可用。HSI PE 正常（2026-10-30 为 13.04）。
  - 采集器 `fetch_hsi_pe` 的失败记录必须保留具体原因（如“未取得有效官方估值：恒生估值响应不是 XLSX”），不能只写“未取得有效官方估值”；
  - 有旧快照的 stale 分支同样保留本次失败原因；
  - `IndexValuationAnalyzer` 在 `val is None` 时从 `collection_records["index_valuation"].error_message` 取原因写入估值区；质量表继续显示同一原因。
- 过期 ISM/美联储/失业率：不进入当前宏观结论，可在数据限制中说明“源未更新”。

## 7. 提示词与模型

- `build_prompt(facts, research)` 改为要求严格 JSON：
  ```json
  {
    "conclusion": {"overall": "", "support": "", "question": ""},
    "evidence_ids": ["index_technical"],
    "risks": [{"id": "technical.incomplete_ohlc", "text": ""}]
  }
  ```
- 模型只写核心结论和风险；指数定位、维度解读、解读限制由程序生成。
- 数字校验沿用个股 v2：事实和模型文本统一去掉千分位逗号，只做同一数值归一；证据 ID 必须属于本批次；风险只能引用候选。
- 禁止买卖、仓位、目标价、评级、支撑压力、预测。
- A 股/港股/美股分别追加市场规则：
  - 港股：南向资金是市场背景；HIBOR/总结余；HSI 官方 PE 为月末快照；新闻是市场新闻。
  - 美股：美国 CPI/10Y；新闻是市场新闻；估值未支持；不输出国内宏观。
  - A 股：国内宏观/资金/新闻为市场背景，不做指数专属因果。
- 模型失败、未配置、未启用时保留确定性 `IndexResearch v2`，不伪造核心结论。

## 8. 兼容与降级

- `IndexReport` 增加 `index_research`、`index_profile`、`market`、`index_style`，旧快照缺省为 `None`/空。
- `commentary` 继续保留；新报告由 `render_index_research` 生成 Markdown。
- Web `renderIndexReport` 优先渲染 `index_research`；没有时回退 `commentary` 旧三段式。
- 旧 `composite_comment`、`tag_*`、`position_coeff` 保留为旧字段，新报告不依赖。
- 重试仍冻结事实、不重采集；`IndexCommentaryRecord` 增加 `research` 快照。
- `write_snapshot` 的 `schema_version` 仍为 1；新字段默认值保证旧快照可读。

## 9. 验收

- A 股宽基/行业/策略：量化章节的数字和口径不变；综合研判按新结构替换旧三段式。
- 港股 HSTECH：新闻有明确“市场新闻”或“未取得”状态；港股通资金仍标市场背景；HSTECH 估值不可用原因保留。
- 美股 SPX/IXIC/DJI：美国 CPI/10Y 可见且带日期；市场新闻可见或明确不可用；估值仍标未支持。
- 三市场综合研判均出现：指数定位、核心结论、维度解读、风险提示、解读限制；模型失败时保留确定性维度。
- 旧报告库、旧快照、报告下载和 390px 展示正常。
- 相关 Ruff/Pyright/pytest 通过；真实服务 `./.venv/Scripts/stock-robot.exe run --host 127.0.0.1 --port 8765` 和内置浏览器验收。

## 10. 风险与未决

- 东方财富关键词检索的新闻相关性不稳定；只能标“市场新闻”，不能称指数专属，需持续抽检。
- 美股 CPI/10Y 源可能延迟；必须标日期和过期状态。
- 过期 ISM/美联储/失业率不补；若未来需要，另立数据源项目。
- HSTECH 官方 PE 源仍不可用；美股指数估值无可靠免费源。
- 旧三段式与新 v2 并存，需保证旧快照 fallback 不丢正文。
- 不默认运行全量门禁；合并或发布前再执行 Full。

## 11. 实施结果

- 七类 `IndexProfile` 已接入单指数报告。未知风格走 `a-default`，维度解读不新增历史表现。
