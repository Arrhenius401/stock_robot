# 策略指数公开官方估值补齐计划

用户已确认使用公开官方数据，不依赖付费权限。

## 已探测事实
- 中证 perf/index-perf 返回实际行情及 peg（官网文案为滚动市盈率）。indexCsiDsPe 会补非交易日、查询起点占位，禁止用于扩大样本。
- 中证 indicator XLS 仅近20条 PE/股息率，没有 PB；旧 AkShare 历史估值接口不存在。
- 官方指数单张包含月末 PB；国证980092含 PE/PB，但 PE 未声明 TTM。中证932365部分单张估值为 --，必须保留缺失。
- PB 日频历史未找到可靠公开接口，不计算或编造 PB 分位。

## 实施与验收
1. 测试先行：官方数据日期排序去重、未来/非正/非有限数过滤、近期截断、252交易日门槛、少于五年真实范围、官方单张错码/日期/缺失/不同口径、缓存及单源失败隔离。
2. 新建 index/valuation_data.py：复用 StrategyDataProvider 网络缓存边界，CSI过去5年官方实际交易日PE；官方PDF布局解析月度PB与未声明TTM的PE。两个源独立失败不互相阻断，网络超时有上限，失败短缓存。快照不得进入历史样本。
3. 扩展 IndexValuationData 默认兼容字段：每指标日期、口径、来源，PE/PB有效日样本数与缺失说明，单张PE单列。接入策略采集进度，保留宽基原逻辑。
4. 分析结果对部分可用报告 partial；没有分位不判断高低估。Web与Markdown展示中文字段和原因，缓存版本更新。
5. 独立规格与质量审查，修复并复核。相关 Ruff/Pyright/pytest，依赖变更冒烟；同步主目录前全量检查一次，既有失败单独记录，不重复未变代码。
6. 同步主目录，真实项目启动路径，浏览器发送515300与980092，确认PE/PB来源日期、真实样本和缺失原因，下载报告保留同样信息。

## 限制
公开数据只承诺已验证的真实覆盖，不能宣称七只指数都有PE/PB日频分位。旧报告不会自动重算，需重新分析。
