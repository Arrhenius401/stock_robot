# 运行环境：Windows 与 Linux

项目要求 Python 3.11 及以上。推荐每个工作副本各自使用 `.venv`，不要把 `stock-robot` 安装到 Anaconda 或用户级 Python 中。这样不同项目的依赖不会互相覆盖。

## 首次安装

Windows PowerShell：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

Linux：

```sh
python3 -m venv .venv
./.venv/bin/python -m pip install -e ".[dev]"
```

若系统没有 `venv` 模块，Debian/Ubuntu 可先安装系统包 `python3-venv`。部分需要编译的第三方依赖在极简 Linux 环境可能还需要 C/C++ 编译器；常规 x86_64 桌面发行版或 CI 环境通常可直接安装预编译包。

## 不激活也可运行

不需要执行 `Activate.ps1` 或 `source .venv/bin/activate`。项目提供两个启动器，它们会定位当前项目的虚拟环境并保留命令退出码：

| 平台 | 命令 |
| --- | --- |
| Windows PowerShell | `.\scripts\stock-robot.ps1 analyze 002714` |
| Linux | `./scripts/stock-robot.sh analyze 002714` |

配置、缓存和其他子命令同样适用，例如：

```powershell
.\scripts\stock-robot.ps1 config set data.disclaimer_accepted true
.\scripts\stock-robot.ps1 cache clear --data-type financial
```

```sh
./scripts/stock-robot.sh config set data.disclaimer_accepted true
./scripts/stock-robot.sh cache clear --data-type financial
```

## 可选：进入目录后直接使用 `stock-robot`

若希望不写启动器前缀，可安装 [direnv](https://direnv.net/)，并按其文档为 PowerShell、bash 或 zsh 安装一次 shell hook。项目根目录已提供 `.envrc`；首次进入仓库后执行一次：

```sh
direnv allow
```

此后每次进入该目录，`direnv` 仅把 `.venv/Scripts`（Windows）或 `.venv/bin`（Linux）加入当前 shell 的 `PATH`，不会激活环境、不会安装依赖，也不会改写全局 Python。于是可直接运行：

```sh
stock-robot analyze 002714
```

不使用 `direnv` 时，继续使用上一节的启动器即可，功能和数据完全一致。
